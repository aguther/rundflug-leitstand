# Cloudflare-Einrichtung – Release 1.10.0

Die aktuelle, vollständige und wiederaufnehmbare Anleitung steht in
[Cloudflare-Neuaufbau](cloudflare-neuaufbau.md). Sie ersetzt die manuelle Pflege fester D1-IDs,
Ressourcennamen und Einrichtungscodes.

Für eine bestehende kompatible Acceptance-Umgebung bleiben deren Namen erhalten. Sie wird mit den
exakten Bestandsnamen und `--resume` aufgenommen; Ressourcen werden nicht automatisch umbenannt,
geleert oder gelöscht.
