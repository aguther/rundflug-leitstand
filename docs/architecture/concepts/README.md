# Architekturkonzepte

Diese Dokumente beschreiben mögliche zukünftige Zielbilder. Sie sind weder Teil der aktuell
implementierten Architektur noch freigegebene Architecture Decision Records. Verbindlich werden
Inhalte erst durch Anforderungen, ADRs und die anschließende Umsetzung.

- [`multi-tenant-multi-event-plan.md`](multi-tenant-multi-event-plan.md) – unverbindliches Zielbild
  für Mandantenfähigkeit, mehrere Veranstaltungen, Plattformadministration und eine versionierte
  Stammdatenbibliothek.
